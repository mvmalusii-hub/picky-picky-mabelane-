# Contributing to Picky Picky Mabelane

Thank you for your interest! Here's how you can help.

## Code of Conduct
Please read [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).

## How to Contribute
1. Fork the repo.
2. Create a branch: `git checkout -b feature/amazing`.
3. Make changes, commit with conventional commits.
4. Run `make test` and `make lint`.
5. Push and open a PR against `main`.

## Development Setup
See [README.md](./README.md) for Docker + Make setup.

## Styleguides
- Backend: ESLint (2 spaces, semicolons, async/await)
- Frontend: Functional components + hooks, CSS modules
- Git commits: `feat:`, `fix:`, `docs:`, `chore:`, etc.

## Recognition
Contributors will be added to `CONTRIBUTORS.md` and receive VIP viewing perks.
